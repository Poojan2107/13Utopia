# Homepage blueprint — fuse applied

**Not screens.** What appears, what mode, what moves, what the copy must do, where SEO lives.  
**System:** [DESIGN-SYSTEM.md](./DESIGN-SYSTEM.md)  
**Chapter list:** brief C21. **Job test:** brief A10 (manifesto / proof / invitation).

Rhythm: **WOW → PROOF → WOW → PROOF → invitation.**  
Narrative (C11): Impossible → Idea → Build → Growth → Proof → Collective → Next.

**Film (Plus-Ex job, 13UTOPiA language):** pinned chapters, not fade-up stacks. One idea per viewport. Display type crops and overflows. Hairline capsules instead of “02 — The challenge” kickers. Cases appear as stills inside the story. Void ↔ cream field flips. Stack = GSAP + ScrollTrigger + SVG + CSS. No Three.js.

Skip **10 Global** on Home until Canada is a real operating fact (S9). Do not decorate two flags.

### 01 — HERO
**Stills:** [RAW hit](./boards/10-ch01-hero-raw.png) → [FUTURE snap](./boards/11-ch01-hero-future.png)  
**Mode:** RAW (3–8s) → snap to FUTURE  
**Motion:** Draw → Morph → Fold → Distort → Reassemble  
**Form:** Void → Orbit/circle → Fold/cube → cursor → Fragment on type → Core  
**Copy (on-screen):**
- Display as architecture (Plus-Ex *job*, our words): **BE / UNREAL** top-left · **BE / UNREASONABLE** bottom-right, overflowing. Syne 800. Cream + amber. Not serif sentence case.
- Capsules: **13UTOPiA** · **13 / 01** · **CREATE · BUILD · GROW** (links)

**SEO:** This is the `H1`. Supporting line is real text in the DOM. CREATE/BUILD/GROW are links.  
**Mobile:** No cursor warp. Tap/scroll advances the morph. One display line at a time if needed.  
**Feel:** 3s what the hell → 10s this is different.

### 03 — WHAT WE ARE
**Stills:** [CREATE](./boards/13-ch03-create.png) → [BUILD](./boards/14-ch03-build.png) → [GROW](./boards/15-ch03-grow.png)  
**Mode:** RAW morph inside FUTURE field  
**Motion:** Morph + Draw  
**Form:** changes per world (Frame/Wave → Node/Grid → Orbit/Flow)  
**Copy:** Three giant words, each transforms the environment:

**WE CREATE.** BRAND · IDENTITY · UX · MOTION · CGI  
**WE BUILD.** WEB · APPS · SAAS · AI · CLOUD · ENGINEERING  
**WE GROW.** SEO · PERFORMANCE · CONTENT · LEADS · STRATEGY  

Under: **Different disciplines. One unreasonable ambition.**

This is “I need to…” Create / Build / Grow.

**SEO:** Three `H2`s or one `H2` + three `H3`s. Each craft is a link to `/capabilities` or a real service page later.  
**Mobile:** Stack the three worlds. Tap to morph. Don’t require horizontal scrub.  
**Feel:** 30s — seriously good. Still WOW.

Crafts live **inside this pin** as capsules under the active word. No separate catalogue chapter.

### 05 — WHAT WE SOLVE
**Still:** [17-ch05-outcomes.png](./boards/17-ch05-outcomes.png)  
**Mode:** FUTURE with one Transform per outcome  
**Motion:** Transform (collide / stretch / reorganize)  
**Copy:**
- **WHAT ARE YOU TRYING TO DO?**
- **LAUNCH · GROW · SCALE · MODERNIZE · AUTOMATE · TRANSFORM**

Meaning:
- Launch — bring something new into the world  
- Grow — attention, customers, revenue *(outcome, not the GROW world — keep type smaller or pair with “demand” in body)*  
- Scale — systems that hold growth  
- Modernize — replace what is outdated  
- Automate — remove unnecessary manual work  
- Transform — change how the business operates  

Selecting Automate → nodes. Grow → expand. Modernize → grid breaks and rebuilds.

This is “I want to…”

**SEO:** Six outcome links to `/solutions/[outcome]` when those pages exist. Definitions in real text.  
**Mobile:** Vertical six. Tap changes the form. No forced horizontal pin.  
**Feel:** Relevance at 60s — they can solve *my* problem.

### 06 — CASE STORIES
**Mode:** FUTURE stage, ART crop on stills, project-specific visual  
**Motion:** Reveal + Transform  
**Copy structure per selected case:**
- CASE STORY nn  
- **The Brief** → **The Friction** → **The Unreasonable Idea** → **The Build** → **The Result**

Not a portfolio grid. Full-bleed cinematic. Two or three on Home. Rest → Work.

Each case: own visual language (identity / UI construct / nodes / graphs) using only the seven verbs.

Placeholders until locked media. Don’t invent results.

**SEO:** Real titles, clients when allowed, outcome text, link to `/work/[slug]`.  
**Mobile:** One case at a time, vertical scroll through the five beats.  
**Feel:** PROOF.

## Normal vs Unreasonable (device)

Use **once** on Home — best between 04 and 05, or inside 05 — not on every chapter.

| Normal | Unreasonable |
|--------|----------------|
| Build a website. | Build a digital ecosystem that changes how the company sells. |
| Run marketing. | Build a growth engine. |
| Use AI. | Rebuild the workflow around AI. |
| Create a brand. | Create a category. |

Pick two pairs for Home. Save the rest for Capabilities / Solutions.
