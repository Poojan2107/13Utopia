# Part A — Positioning & architecture

## A1. The core challenge

Two audiences, one company:

**Creative / growth clients** — branding, creative direction, UI/UX, CGI / motion, marketing, SEO, growth.

**Technology / business clients** — websites, SaaS, apps, AI, automation, cloud, engineering, digital transformation, CTO advisory.

If every offering sits equally on one site, the visitor thinks:

> “13UTOPiA does everything.”

That is exactly what we do **not** want.

Instead:

> **13UTOPiA is a multidisciplinary company that combines imagination, technology and growth to build what conventional companies cannot.**

That is where **“Be Unreal. Be Unreasonable.”** becomes powerful.

# Part B — Visual universe (still not page UI)

Four references, four ingredients — **not one site to imitate**:

| Reference | Steal (principle) |
|-----------|-------------------|
| [Munich / Qode](https://munich.qodeinteractive.com/) | outlined graphic language, line-art / SVG-like accents, graphic systems |
| [RPA Comunicación](https://rpacomunicacion.com/) | energetic storytelling, intro sequence, oversized words, scroll rhythm, image transitions, expressive personality |
| [KOTA](https://kota.co.uk/) | restrained premium structure, editorial type, curved/organic transitions, commercial storytelling |
| [Made With GSAP](https://madewithgsap.com/) | interaction/motion as a major part of the experience, not decoration |

Combine into something **different from all four**.

### Direction line
**UNREAL VISUALS. UNREASONABLE INTERACTIONS. SERIOUS BUSINESS RESULTS.**

Two personalities at once:

- **WOW** — creative, strange, unexpected, memorable  
- **TRUST** — intelligent, precise, technically credible, commercially mature  

That tension is the signature. A CEO must not wonder if we can build SaaS, fix technology, grow a company, or deliver an enterprise project.

## B1. A visual universe, not a UI collage

Do **not**: Munich shapes + RPA scroll + KOTA curves + GSAP = “the design.”

Create a **13UTOPiA visual grammar**:

**OUTLINES** — thin geometric outlines appear / disappear / reconfigure  
**ORGANIC FORMS** — curves and blobs occasionally interrupt the rigid grid  
**TYPOGRAPHY** — huge words become visual objects  
**MOTION** — elements do not merely fade in; they **transform**  
**IMPERFECTION** — some things intentionally break the grid  
**SYSTEM** — despite the chaos, everything follows a hidden mathematical system  

That last part makes it premium, not gimmicky.

## B2. Hero idea (experience, not a screen to draw yet)

Do **not** start with “13UTOPiA is a creative technology company…”

Imagine entering:

- Screen almost empty  
- Thin outlined shape appears (maybe a circle)  
- Becomes a cube  
- Cube unfolds  
- Geometry responds to cursor  
- Small: **13UTOPiA**  
- Enormous: **BE UNREAL. BE UNREASONABLE.**  
- **UNREAL** can stretch, distort, fragment, rotate  
- **UNREASONABLE** can become almost too large for the viewport  
- System resolves to: **We imagine beyond the obvious. We build beyond the expected.**  
- Then: **CREATE · BUILD · GROW**

## B11. Careful with animation

Not fade-in + slide-up + parallax everywhere (template feel).

Define **approximately 5–7 signature interaction behaviors**:

| # | Behavior |
|---|----------|
| 01 | **Morph** — Shape A → Shape B |
| 02 | **Draw** — outlines literally draw themselves |
| 03 | **Distort** — type responds to scroll/cursor |
| 04 | **Reveal** — images/content emerge from unusual masks |
| 05 | **Transform** — one section physically becomes another |
| 06 | **Break** — elements escape the grid |
| 07 | **Reassemble** — broken elements come back into a system |

Those seven **are** the 13UTOPiA motion language.

## B12. SEO must coexist

Crawlable text, proper H1/H2, indexable service pages, internal linking, accessible nav, descriptive metadata, schema, fast critical content, optimized images/video, Core Web Vitals.

**The browser sees a great website. The visitor sees a completely unreasonable website.**

## B13. Performance is a design constraint from day one

GSAP, SVG, large imagery, video, 3D, scroll, morphing, transitions — design with performance in mind.

Prefer: **GSAP + ScrollTrigger + SVG + CSS + optimized WebGL/3D where genuinely necessary.**  
Not heavy libraries on everything. Every wow needs a reason.

# Part C — Design DNA v0.1

**Nothing gets coded until we’re broadly aligned on this.**

## C01. The big idea

**BE UNREAL. BE UNREASONABLE.** — operating philosophy of the website.

**UNREAL** — imagine beyond convention; make the ordinary extraordinary; think creatively; explore what doesn’t exist yet; make people feel something.

**UNREASONABLE** — don’t accept arbitrary limitations; challenge the brief; question the obvious solution; engineer ambitious ideas; pursue disproportionate outcomes.

Invisible third principle: **MAKE IT WORK.**  
Not an art experiment. Brands, products, technology and growth systems for real businesses.

Design tension:

> **Dream like an artist. Think like a strategist. Build like an engineer. Grow like an entrepreneur.**

## C02. What should someone feel?

| Time | Feeling |
|------|---------|
| First 3 seconds | “What the hell is this?” — curiosity |
| 10 seconds | “This is different.” — interest |
| 30 seconds | “These people are seriously good.” — trust |
| 60 seconds | “They can actually solve my problem.” — relevance |
| End | “I want to talk to them.” — conversion |

That is the UX target.

## C03. Brand personality (six)

01 **BOLD** — never timid  
02 **INTELLIGENT** — never superficial  
03 **PLAYFUL** — never boring  
04 **EXPERIMENTAL** — never predictable  
05 **PRECISE** — never messy  
06 **AMBITIOUS** — never generic  

The combination that matters: **Playful + precise.**

## C04. The visual contradiction

- RIGID × ORGANIC — grid + curves  
- DIGITAL × HUMAN — technology + photography/people  
- MINIMAL × MAXIMAL — huge typography + tiny details  
- ORDER × CHAOS — precise layout + elements breaking the grid  
- BLACK/WHITE × ELECTRIC ACCENT — restrained base + moments of visual explosion  
- STATIC × MOTION — editorial layouts + insane transitions  

This contradiction is **UNREAL × UNREASONABLE**.

## C05. Visual language — five ingredients

**A. OUTLINE FORMS** — Munich as starting *principle*, not reproduction. Forms: circles, distorted circles, orbital systems, grids, impossible geometry, fragments, waves, capsules, nodes, abstract “13” forms. They **move**. Not decoration.

(Further ingredients continue through type, color, shapes, scroll, motion below.)

## C06. The 13 form system (internal vocabulary)

01 ORBIT · 02 LOOP · 03 GRID · 04 WAVE · 05 VOID · 06 NODE · 07 FOLD · 08 CORE · 09 FLOW · 10 FRAME · 11 SIGNAL · 12 FRAGMENT · 13 UTOPIA

## C07. Typography

Not conventional heading / paragraph / button everywhere.

Typography sometimes behaves like an image: stretched, outlined, clipped, masked, huge, rotated, fragmented, animated, partially outside the viewport.

Body copy remains **extremely readable**.

**Expressive display typography** × **Editorial readable typography.**

## C09. Color — do not decide final colors yet

Three visual routes; choose after testing:

**ROUTE A — MONOCHROME + ELECTRIC** — Black, White, Grey, one aggressive accent. Futuristic.

**ROUTE B — DARK UTOPIA** — Near-black, off-white, deep tones, multiple controlled accents. Cinematic.

**ROUTE C — WHITE UTOPIA** — Off-white, black, soft neutral, one unexpected fluorescent/electric accent. Premium/editorial.

Instinct: **mostly monochrome + one unmistakable signature accent.** Test visually before committing.

## C10. Shapes — visual physics, not random blobs

| State | Behavior |
|-------|----------|
| Idle | slow movement |
| Cursor | shape reacts |
| Scroll | shape transforms |
| Section transition | shape becomes the next section |
| Hover | shape changes state |
| Click | shape explodes / reconfigures |

The entire website is alive.

## C11. Scroll behaviour — chapters

Not a stack of sections. User moves through:

**CHAPTER 01 THE IMPOSSIBLE** → **02 THE IDEA** → **03 THE BUILD** → **04 THE GROWTH** → **05 THE PROOF** → **06 THE COLLECTIVE** → **07 THE NEXT**

Narrative, not a brochure.

## C12. Motion language

Signature motions (small set):

**MORPH · DRAW · DISTORT · REVEAL · COLLIDE · BREAK · REASSEMBLE**

(Align with B11: Transform is the section-becomes-section verb; Collide is elements meeting. Keep both in the vocabulary; do not invent a 20th style.)

Made With GSAP: motion as organizing principle, not a transition effect.

## C13. Most important motion rule

**Nothing moves without a reason.**

If an object moves — it communicates something.  
If text changes — it reveals something.  
If a shape transforms — it connects two ideas.  
If the page transitions — it advances the story.

Saves us from a flashy, exhausting website.

## C14. The grid

Strong grid. Probably **12-column desktop**. Then deliberately violate it.

Normal: content in the container.  
Unreasonable: content bleeds, overlaps, sits between columns.

Grid = discipline. Breaking it = personality.

## C15. Image direction

- **ART DIRECTED** — photography created for 13UTOPiA  
- **SYNTHETIC** — CGI / 3D / AI-assisted imagery / abstract worlds  

Can combine: **real human + impossible environment.**

Sells creative work and technology work.
