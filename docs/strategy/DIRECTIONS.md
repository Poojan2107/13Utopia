## What every direction must still do

The brief does not change between boards.

- **Be Unreal. Be Unreasonable.** is the philosophy, not a caption.
- WOW and TRUST at once. A CEO must believe we can build SaaS and grow a company.
- CREATE / BUILD / GROW + six outcomes + Case Stories + Collective.
- 5–7 motions. Nothing moves without a reason.
- Semantic HTML under motion. Mobile is a different dance.
- 40% technology · 30% studio · 20% editorial · 10% controlled chaos.
- Color still follows brief C09 (three *routes*, test before commit). Each direction below is a *test* of a route, not a locked palette.

## 01 — UTOPIA / RAW

**Brief:** Dark, experimental, distorted typography, outlines, aggressive motion.

**Color route it tests:** A — monochrome + one aggressive electric accent (outline only).

**Still:** Huge UNREAL, cropped and fractured. Thin lime wireframe mid-morph (circle → cube). Black void.

| | |
|--|--|
| Field | Pure black |
| Accent | One electric lime *line* — never a fill, never a blob |
| Type | Display as violence: stretch, fragment, overflow the viewport, then snap |
| Forms | Outline physics. Draw, break, reassemble |
| Motion | Break → Reassemble. Distort on the tagline |
| Steal | RPA’s *energy* (oversized sequence). Munich’s *outline as language* |
| Avoid | RPA’s party-site chaos. Munich’s theme-kit shapes. Fade-in wallpaper |

**3s:** What the hell is this.  
**10s:** This is different.  
**30s risk:** Art school — unless the snap-to-order is brutal and fast. TRUST has to arrive after the hit.

**Where it belongs if not the whole site:** load, first hero hit, CREATE / BUILD / GROW morph, Normal vs Unreasonable flips.

**If it were the whole site:** maximum memory, weakest CEO trust. WOW without PROOF.

## 02 — UTOPIA / FUTURE

**Brief:** Light/dark contrast, precision grid, futuristic forms, technology-driven motion.

**Color route it tests:** B — dark utopia, near-black, off-white, one warm controlled light (not a paint-bucket brand color).

**Still:** 12-column grid. Matte cream 3D **13** with weight and shadow. BE UNREASONABLE as a system label. Amber as *light*.

| | |
|--|--|
| Field | Near-black + faint 12-col grid |
| Accent | Warm directional light on form — amber as illumination |
| Type | Set to the grid. Precise. Unreasonable as a specification, not a scream |
| Forms | Geometry that extrudes, unfolds, becomes product / system |
| Motion | Morph → Draw. Engineering reveals |
| Steal | KOTA’s *commercial spine* (clarity, craft, results). Grid as discipline |
| Avoid | KOTA’s look. Generic “dark SaaS” templates. Glassmorphism. Gradient orbs |

**3s:** Serious.  
**10s:** Premium technology.  
**30s:** Highest TRUST. Looks like it can ship. Risk: if the RAW hit never happens, it can still feel like a very good corporate site.

**Where it belongs if not the whole site:** default world, capabilities, solutions, proof, connect, conversion.

**If it were the whole site:** safest commercially. Least “what the hell.” May miss the 10% controlled chaos the brief requires.

## 03 — UTOPIA / ART

**Brief:** Editorial, highly artistic, organic curves, unusual compositions, cinematic transitions.

**Color route it tests:** C — white utopia. Off-white, black ink, no second accent. Crop is the accent.

**Still:** Paper. Cropped Didot BE UNREAL. One ink curve. Silence. (The still may carry a manifesto line — that is copy-as-image, not a webpage.)

| | |
|--|--|
| Field | Warm off-white uncoated paper |
| Accent | None. Black ink. Crop and emptiness |
| Type | Editorial cover. Letters leave the frame |
| Forms | One organic curve that interrupts, then becomes structure |
| Motion | Reveal → Silence. Slow crop. No fidget |
| Steal | KOTA’s *restraint and pacing*. Magazine storytelling |
| Avoid | Pretty studio that cannot look like it builds products. Decorative blobs pretending to be “organic” |

**3s:** Taste.  
**10s:** This is considered.  
**30s:** Trust via craft. Risk: “beautiful studio — can they build my SaaS?”

**Where it belongs if not the whole site:** Perspective, process statements, the silence between insane chapters, Collective humanity.

**If it were the whole site:** unforgettable pacing, weak BUILD signal.
