# Decisions

## Dual identity
Creative services (branding, CGI, UI) get craft energy. Professional services (cloud, strategy, SEO ops) stay clear and serious. Every page: **one** domain signature moment. Why: boss needs both client types to trust the studio.

## Hero
Left = *Be Unreal / Be Unreasonable* (editorial). Right = 3D wordmark. Mobile: mark → type → CTAs. Why: brand object + tagline both hero-level without clutter.

## Home order
Hero → Perspective teaser → Work → Capabilities → Solutions → Process → Proof → Connect. Why: POV then proof then offer then convert.

## Media
Home uses **placeholders** until locked assets land. No legacy pairings (wrong logo on wrong client). Why: mismatched sample media reads as broken, not premium.

## India only
Canada deferred. No Canada office UI. Why: ops lock.

## Motion
Max four signature moves on home (hero reveal, work pin, index hover, connect scrub). Why: speed + SEO; no carnival.

## Tagline
Subtle site-wide echo. Why: identity continuity without shouting.

## Accents
Void / cream / amber stay the base. Extra bright hues only if they earn their place and are logged here. v1: no new hue tokens.
