# Decisions

## Dual identity
Creative services (branding, CGI, UI) get craft energy. Professional services (cloud, strategy, SEO ops) stay clear and serious. Every page: **one** domain signature moment. Why: boss needs both client types to trust the studio.

## Hero (superseded 2026-08-13)
**Was:** Left = tagline, right = 3D wordmark (two columns).  
**Now:** Full-viewport takeover. The 3D mark is the room; *Be Unreal / Be Unreasonable* lives in the same frame. Header + one Talk remain. Why: the split read as a brochure screen, not a hero. Mobile is a crop (type on a bottom wash), not a squashed desktop.

## Home order
Hero → Perspective whisper → Work → Capabilities → Solutions → Process → Proof → Connect. Why: brand, then evidence, then offer, then convert. Perspective is a line, not a second hero.

## Media
Home uses **placeholders** until locked assets land. No legacy pairings (wrong logo on wrong client). Why: mismatched sample media reads as broken, not premium.

## India only
Canada deferred. No Canada office UI. Why: ops lock.

## Motion
Signature only: hero reveal, work pin, work hover/focus, connect settle. Why: speed + SEO; no carnival.

## Tagline
Subtle site-wide echo. Why: identity continuity without shouting.

## Accents
Void / cream / amber stay the base. Extra bright hues only if they earn their place and are logged here. v1: no new hue tokens.

## Scope this pass
Homepage only (5A). Shell and interiors stay. See [HOME-BRIEF.md](./HOME-BRIEF.md).
